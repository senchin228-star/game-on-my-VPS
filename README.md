# Simple Network Game (C, UDP)

Учебный проект: простая сетевая игра на C с использованием UDP-сокетов. Клиент и сервер — два отдельных бинарника, обмениваются данными по кастомному текстовому протоколу.

## Структура проекта

```
.
├── server.c           # логика сервера: приём сигналов, хранение позиций игроков
├── client.c           # логика клиента: меню, обработка клавиш, отправка сигналов
├── protocol.h          # общие структуры и enum команд (PLAYER_SIGNALS)
├── config.h            # реальные IP/порт сервера (в .gitignore, не в репозитории!)
├── config.example.h    # шаблон config.h — скопируйте и заполните своими данными
├── Makefile
└── README.md
```

## Сборка

```bash
make
```

Соберёт два бинарника: `server` и `client`.

```bash
make clean
```

Удалит собранные бинарники.

## Настройка перед запуском

Файл `config.h` **не хранится в репозитории** — там указаны реальный IP и порт сервера. Перед сборкой:

```bash
cp config.example.h config.h
```

И заполните `SERVER_IP` / `SERVER_PORT` своими значениями.

## Запуск

Сервер (на VPS или локально):
```bash
./server
```

Клиент:
```bash
./client
```

## Статус проекта

В разработке / учебный проект. Текущая версия: базовый протокол (подключение игрока, движение по 4 направлениям), сервер хранит позиции игроков и рассылает состояние клиентам.
